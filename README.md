## 使命

用自然语言完成日常记账，替代手机 APP 手动录入。提供可审计、可验证、可导出的账本数据。

## 核心能力

- **自然语言记账**：支持「午饭 35」「股票卖出 XX 500」等输入，自动分类
- **分类体系**：2 级分类（3 收入大类 + 11 支出大类，~50 子类）
- **查询分析**：今日/本月/按分类/投资等维度查询
- **审计回显**：每次操作带交易 ID、总记录数、查询范围/条件/命中笔数
- **修正学习**：用户纠正后自动追加关键词规则

## 技术栈

- **存储**：SQLite（单文件，零依赖）
- **引擎**：Python 3（`ledger.py`）
- **运行环境**：Slock Agent 平台，Claude 模型驱动
